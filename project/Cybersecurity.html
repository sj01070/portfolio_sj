AI 사이버보안 플랫폼

UI/UX Design · 기여도 100% · 제작기간 3주 · 개인 프로젝트

프로젝트 개요

프로젝트 목표
사이버 보안 분야를 이해하고 UI/UX 역량을 적용하고 AI, Cloud, Identity, Application 등 다양한 환경에서 발생하는 보안 정보를 하나의 공간에서 확인하고 대응할 수 있는 기능 제공을 목표로 한다.

디자인 목표
복잡한 보안 정보의 관계를 정리해 다른 정보의 관계를 파악할 수 있으며, AI와 사용자의 역할을 구분해 AI에게 의존하는 것이 아닌 사용자가 최종 판단을 내릴 수 있도록 한다.

프로젝트 타입
다양한 환경의 보안 상태를 통합적으로 보안 상태를 확인하고, 조사하여 대응까지 연결할 수 있는 보안 운영 플랫폼

프로젝트 유형
B2B SaaS Platform, End-to-End Product Design

제작 방향

모든 정보를 한번에 보여주는 것이 아닌 사용자에게 필요한 정보를 요약 → 목록 → 상세 → 대응 조치 순으로 제공된 내용을 확인하고 AI는 사용해주는 보조의 역할로서 최종 대응은 사용자가 직접 결정하도록 제작되었습니다.

핵심 화면

보안 정보를 많이 보여주는 것보다 사용자가 현재 무엇을 확인해야 하고, 무엇을 이해해야하며, 어떤 판단을 내려야 하는지를 먼저 정의 후 사용자에게 필요한 정보에 집중할 수 있도록 레이아웃을 조정하면서 UI/UX를 설계하였습니다.
