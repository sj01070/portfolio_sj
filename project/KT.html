Kt 기업무선 관제플랫폼

UI/UX Design · 기여도 100% · 제작기간 9개월 · 실무 프로젝트

프로젝트 개요

프로젝트 목표
실시간으로 데이터를 수집하고 결합을 통하여 위험상황을 유연하게 감지하고 다양한 IoT 디바이스에 연결하여 차세대 데이터 통합 모니터링 업무를 제공한다.

디자인 목표
클라이언트가 추구하는 컨셉에 맞춰 정보의 우선순위를 고려해 복잡한 정보를 빠르게 파악할 수 있도록 데이터 특성에 맞는 UI설계와 디자인 시스템을 구축하고, 대시보드인 사용자 맞춤형 위젯 서비스 기능과 자연스럽게 연계될 수 있도록 디자인을 통일시킨다.

프로젝트 타입
고객 맞춤형 통합 관제기능을 실시간으로 분석, 치리, 시각화 하여 위험 상황을 자동 대응할 수 있는 기업 운영 플랫폼

프로젝트 유형
B2B SaaS Platform, B2C Brochure Design

담당업무

담당 범위
UI 디자인 · UX 설계 과정 협업 · 클라이언트 소통 · 개발자 협업 · 디자인 QA 담당

대시보드 디자인

대시보드 정보 구조 및 화면 전체 구성 및 지도/아이소메트릭 뷰 전환 화면 UI 설계, 사용자 맞춤형 위젯기반 대시보드 디자인, 대시보드 내 사용되는 아이콘/아이소메트릭 콘텐츠 제작

행사 시연 용 대시보드 디자인

시연 용 단페이지로 제작 된 데이터 처리기능 홍보 대시보드 UI화면 디자인 설계

브로슈어 디자인

브랜드 아이덴티티에 맞춰 새롭게 개발 된 제품의 홍보를 위한 박람회 배포용 브로슈어 디자인
